PASO 1

Deberemos instalar Antigravity CLI, ya que es una interfaz de línea de comandos para trabajar directamente con agentes de IA desde la terminal, lo que hace que el trabajo sea más potente y rápido. Antes de nada, deberemos descargar esta aplicación desde Antigravity CLI.

PASO 2

Crearemos los diseños de nuestra aplicación por ejemplo con una herramienta como Stitch de Google. Esta web de diseño generará con IA las pantallas que le especifiquemos. Después, podremos perfilar el resultando pidiéndole que modifique o elimine elementos, ya que tiende a crear pantallas demasiado completas y complejas.
Una vez creadas las pantallas, elegiremos una paleta de diseño y las seleccionaremos para exportarlas y descargar un archivo .zip.

PASO 3

Para llevar el control de lo que genere la IA, debemos usar las skills preparadas para que los proyectos se generen siguiendo nuestras especificaciones. Si aún no las hemos descargado, están en un repositorio de la organización PMDM llamado skillproyectos. Descomprimiremos la carpeta descargada dentro de AndroidPortable y eliminaremos todo menos la carpeta .agents. Dentro de skillproyectos, crearemos una carpeta DESIGN, donde descomprimiremos los diseños que hayamos realizado en Stitch. Además, crearemos una carpeta imagenes, donde se alojarán las imágenes generadas por la IA para los mocks.

PASO 4

Ejecutaremos AndroidCLI.bat, que está dentro de la carpeta AndroidPortable. Este archivo crea las variables de entorno necesarias para que el CLI de Antigravity encuentre más rápidamente los archivos que necesita. Se abrirá una consola de comandos. Si queremos comprobar que las variables se han creado correctamente, podremos usar el comando set.
Ahora solo nos queda entrar en la carpeta skillproyectos con el comando cd e iniciar el cliente de Antigravity con el comando agy. La primera vez Antigravity pedirá que nos auntentiquemos con una cuenta válida, si todo va bien nos dará la bienvenida y esperará a que introduzcamos los comandos necesarios.

PASO 5

Deberemos establecer el agente en modo plan. Así, antes de ponerse a crear código, generará un documento con el plan previsto, que podremos corregir y perfilar para que la aplicación quede bien desde el primer momento. Siempre será más eficiente generar la aplicación correctamente desde el principio que pedir después a los agentes que añadan parches. Para ello, podrás presionar Shift + Tab para alternar en tiempo real entre los modos de ejecución disponibles (default, accept-edits y plan). Elige el modo plan.

PASO 6

Le pediremos el plan con algún texto explicando lo que queremos de forma clara, por ejemplo de la siguiente manera:

/plan Genera un proyecto de Android basado en el diseño de @[DESIGN]. Genera un mock con datos de prueba y si el mock tiene url de imágenes, las generas como imágenes reales y las guardas en @[imagenes]. El proyecto se llamará GestorColecciones.

Con la información que recaba del diseño que le hemos pasado, comenzará a generar el plan de la APP. Esperaremos a que haga su trabajo y genere el plan.
Si no especificamos que las confirmaciones sean automáticas, tendremos que ir aceptando todas las preguntas. Para ello usamos el comando \config

/config [enter]
seleccionar en
Tool Permission always-proceed

PASO 7

Cuando el agente termine, nos pedirá que revisemos y confirmemos el plan. Para abrir el archivo del plan, usaremos el comando /artifact y pulsaremos Open, que aparecerá en azul en la parte de abajo. Una vez abierto, lo leeremos y modificaremos o añadiremos lo que consideremos necesario. Es un documento .md que podremos editar en un editor de texto; en él se especifican claramente los comandos para cada tarea.
Una vez realizados los cambios, no olvides guardar antes de salir. Después, seleccionaremos la opción Approve y el agente comenzará a trabajar.

PASO 8

Una vez terminado el proyecto, el agente lo compilará y ejecutará las pruebas unitarias para detectar y corregir posibles errores. Cuando haya acabado, solo tendremos que abrir la carpeta con Android Studio para ver y ejecutar el proyecto.
