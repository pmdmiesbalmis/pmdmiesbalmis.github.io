Parte 1. Pantalla Lista

Deberemos añadir una lista con los elementos de nuestra colección. Como es una nueva Screen, deberás crear el paquete pieza donde añadiremos todos los archivos necesarios (ViewModel, Screen, Event, etc). La pantalla principal deberá tener un LazyColumn con un aspecto similar al que se muestra en la imagen (poniendo imaginación de vuestra parte). Crearemos un componente PiezaItemCard que representará cada uno de los elementos del LazyColumn.
Como se puede ver en la imagen, en la parte superior de la lista hay un TextField para realizar filtrados (se pasa el código en el enlace inferior) y un FilterChip. La búsqueda del TextField se realizará por nombre o descripción, mientra que la del FilterChip sería por categoría, se necesitará añadir un tipo enumerado con la clasificación de las piezas. Para ello deberás de crear un enumerado en Pieza del modelo, mientras que en PiezaMock no será enumerado sino de tipo entero. El código de transformación se realizará en RepositoryConverter.

Parte 2. Pantalla Detalle

El ejercicio tiene una segunda parte donde crearemos el paquete editar que incluirá todos los archivos necesarios para realizar una nueva pantalla con su funcionalidad. Esta pantalla nos va a servir para mostrar y modificar el detalle de una pieza en concreto. Su aspecto será el que vemos a la derecha.
Como se puede ver, la pantalla está formada por una primera parte con una imagen principal, que será la misma que se muestra en la lista de todos los artículos. Además, en la parte inferior se puede ver que hay un LazyRow que mostrará diferentes perspectivas o información (en imagen) del mismo artículo. Si se pulsa en un elemento del LazyRow, se mostrará la imagen pulsada en la imagen principal.

Info

Las url de las imágenes se deberán guardar en el Mock, para ello deberás crear una nueva propiedad llamada listaFotos de tipo String en la que deberás guardar las url de las fotos separadas por ;. En el Modelo listaFotos será de tipo List<String> y deberás hacer las conversiones de un tipo a otro en RepositoryConverter. Como es normal, deberás añadir las funciones necesarias en PiezaDaoMock y en PiezaRepository para acceder a la nueva propiedad.

La otra parte de la pantalla está formada por los TextField necesarios para mostrar/editar el resto de información de nuestra pieza. Además de dos botones que nos permitan borrar la pieza o guardar los cambios. Para que se pueda ver todo el contenido, se deberá aplicar Scroll a la parte que incluye los datos, No a la de las imágenes.

Se pasa el código de los TextFiel que se muestran en la pantalla, por si queréis reutilizar alguna funcionalidades.

@Composable
private fun TarjetaInformacionBasica(
    uiState: PiezaDetalleEditarUiState,
    onPiezaDetalleEditarEvent: (PiezaDetalleEditarEvent) -> Unit,
    modifier: Modifier = Modifier
) {
    Card(
        shape = RoundedCornerShape(16.dp),
        colors = CardDefaults.cardColors(
            containerColor = MaterialTheme.colorScheme.surfaceContainerLowest
        ),
        border = BorderStroke(1.dp, GlacierSecondary.copy(alpha = 0.15f)),
        elevation = CardDefaults.cardElevation(defaultElevation = 2.dp),
        modifier = modifier.fillMaxWidth()
    ) {
        Column(
            modifier = Modifier
                .fillMaxWidth()
                .padding(16.dp),
            verticalArrangement = Arrangement.spacedBy(14.dp)
        ) {
            Text(
                text = "Información Básica",
                style = MaterialTheme.typography.labelLarge.copy(fontWeight = FontWeight.SemiBold),
                color = MaterialTheme.colorScheme.onSurface
            )

            OutlinedTextFieldName(
                modifier = Modifier.fillMaxWidth(),
                label = "Nombre o Título de la Pieza",
                nameState = uiState.titulo,
                validacionState = uiState.validacion.validacionTitulo,
                onValueChange = {
                    onPiezaDetalleEditarEvent(
                        PiezaDetalleEditarEvent.OnTituloCambiado(
                            it
                        )
                    )
                }
            )

            DesplegableCategoriaPieza(
                categoriaSeleccionada = uiState.categoria,
                onCategoriaCambiada = {
                    onPiezaDetalleEditarEvent(
                        PiezaDetalleEditarEvent.OnCategoriaCambiada(
                            it
                        )
                    )
                }
            )

            CamposEpocaYAutor(
                uiState = uiState,
                onPiezaDetalleEditarEvent = onPiezaDetalleEditarEvent
            )

            OutlinedTextFieldName(
                modifier = Modifier.fillMaxWidth(),
                label = "Valor Estimado (€)",
                nameState = uiState.valorEstimado,
                validacionState = uiState.validacion.validacionValor,
                onValueChange = {
                    onPiezaDetalleEditarEvent(
                        PiezaDetalleEditarEvent.OnValorCambiado(
                            it
                        )
                    )
                }
            )
        }
    }
}

@OptIn(ExperimentalMaterial3Api::class)
@Composable
private fun DesplegableCategoriaPieza(
    categoriaSeleccionada: CategoriaColeccion,
    onCategoriaCambiada: (CategoriaColeccion) -> Unit,
    modifier: Modifier = Modifier
) {
    var categoriaMenuExpandido by remember { mutableStateOf(false) }

    ExposedDropdownMenuBox(
        expanded = categoriaMenuExpandido,
        onExpandedChange = { categoriaMenuExpandido = it },
        modifier = modifier.fillMaxWidth()
    ) {
        OutlinedTextField(
            value = categoriaSeleccionada.nombreVisible,
            onValueChange = {},
            readOnly = true,
            label = { Text("Categoría") },
            trailingIcon = { ExposedDropdownMenuDefaults.TrailingIcon(expanded = categoriaMenuExpandido) },
            colors = OutlinedTextFieldDefaults.colors(
                focusedContainerColor = MaterialTheme.colorScheme.surfaceContainerLowest,
                unfocusedContainerColor = MaterialTheme.colorScheme.surfaceContainerLowest
            ),
            shape = RoundedCornerShape(8.dp),
            modifier = Modifier
                .fillMaxWidth()
                .menuAnchor()
        )
        ExposedDropdownMenu(
            expanded = categoriaMenuExpandido,
            onDismissRequest = { categoriaMenuExpandido = false }
        ) {
            CategoriaColeccion.entries
                .filter { it != CategoriaColeccion.TODAS }
                .forEach { cat ->
                    DropdownMenuItem(
                        text = { Text(cat.nombreVisible) },
                        onClick = {
                            onCategoriaCambiada(cat)
                            categoriaMenuExpandido = false
                        }
                    )
                }
        }
    }
}

@Composable
private fun CamposEpocaYAutor(
    uiState: PiezaDetalleEditarUiState,
    onPiezaDetalleEditarEvent: (PiezaDetalleEditarEvent) -> Unit,
    modifier: Modifier = Modifier
) {
    Row(
        modifier = modifier.fillMaxWidth(),
        horizontalArrangement = Arrangement.spacedBy(12.dp)
    ) {
        Box(modifier = Modifier.weight(1f)) {
            OutlinedTextFieldName(
                modifier = Modifier.fillMaxWidth(),
                label = "Año",
                nameState = uiState.epoca,
                validacionState = uiState.validacion.validacionEpoca,
                onValueChange = {
                    onPiezaDetalleEditarEvent(
                        PiezaDetalleEditarEvent.OnEpocaCambiada(
                            it
                        )
                    )
                }
            )
        }
        Box(modifier = Modifier.weight(1f)) {
            OutlinedTextFieldName(
                modifier = Modifier.fillMaxWidth(),
                label = "Autor",
                nameState = uiState.autor,
                validacionState = uiState.validacion.validacionAutor,
                onValueChange = {
                    onPiezaDetalleEditarEvent(
                        PiezaDetalleEditarEvent.OnAutorCambiado(
                            it
                        )
                    )
                }
            )
        }
    }
}

@Composable
private fun BotonesAccionPieza(
    esEdicion: Boolean,
    cargando: Boolean,
    onGuardarClick: () -> Unit,
    onEliminarClick: () -> Unit,
    modifier: Modifier = Modifier
) {
    Column(
        modifier = modifier.fillMaxWidth(),
        verticalArrangement = Arrangement.spacedBy(10.dp)
    ) {
        BotonGuardarPieza(
            esEdicion = esEdicion,
            cargando = cargando,
            onClick = onGuardarClick
        )

        if (esEdicion) {
            BotonEliminarPieza(
                cargando = cargando,
                onClick = onEliminarClick
            )
        }
    }
}

@Composable
private fun BotonGuardarPieza(
    esEdicion: Boolean,
    cargando: Boolean,
    onClick: () -> Unit,
    modifier: Modifier = Modifier
) {
    Button(
        onClick = onClick,
        enabled = !cargando,
        shape = RoundedCornerShape(12.dp),
        colors = ButtonDefaults.buttonColors(
            containerColor = GlacierPrimary,
            contentColor = Color.White
        ),
        modifier = modifier
            .fillMaxWidth()
            .height(50.dp)
    ) {
        if (cargando) {
            CircularProgressIndicator(
                color = Color.White,
                modifier = Modifier.size(22.dp),
                strokeWidth = 2.dp
            )
        } else {
            Icon(
                imageVector = Icons.Default.Inventory2,
                contentDescription = null,
                modifier = Modifier.size(20.dp)
            )
            Spacer(modifier = Modifier.width(8.dp))
            Text(
                text = if (esEdicion) "Guardar Cambios en Catálogo" else "Publicar Pieza en Catálogo",
                style = MaterialTheme.typography.labelLarge.copy(fontWeight = FontWeight.SemiBold)
            )
        }
    }
}

@Composable
private fun BotonEliminarPieza(
    cargando: Boolean,
    onClick: () -> Unit,
    modifier: Modifier = Modifier
) {
    OutlinedButton(
        onClick = onClick,
        enabled = !cargando,
        shape = RoundedCornerShape(12.dp),
        colors = ButtonDefaults.outlinedButtonColors(
            contentColor = GlacierError
        ),
        border = BorderStroke(1.dp, GlacierError.copy(alpha = 0.4f)),
        modifier = modifier
            .fillMaxWidth()
            .height(50.dp)
    ) {
        Icon(
            imageVector = Icons.Default.Delete,
            contentDescription = null,
            modifier = Modifier.size(18.dp)
        )
        Spacer(modifier = Modifier.width(8.dp))
        Text(
            text = "Eliminar Pieza del Catálogo",
            style = MaterialTheme.typography.labelLarge.copy(fontWeight = FontWeight.SemiBold)
        )
    }
}
